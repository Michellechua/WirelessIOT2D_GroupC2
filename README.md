# WirelessIOT2D_GroupC2

This repository contains the code for three ESP32 nodes, each handling a different function in the IoT system.  
Each node runs independently and connects to ESP RainMaker to upload sensor data and receive control signals.

---

## Node Overview

- **/nodeA_switch**  
  ESP32 Node A code for controlling an OLED screen and a buzzer based on rain detection.

- **/nodeB_weather_update**  
  ESP32 Node B code for collecting weather data using a DHT11 sensor and an FC-37 rain sensor.

- **/nodeC_motion**  
  ESP32 Node C code for detecting motion using a PIR sensor.
